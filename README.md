# Manpreet Kaur — Developer Portfolio 🚀

A modern, fully responsive personal developer portfolio website built with **React 18**, **Tailwind CSS**, and **Lucide React Icons**.

## 🌐 Live Preview
> Open `index.html` via a local server or deploy to Vercel / Netlify.

## ✨ Features
- **Hero Section** — Catchy heading, subtitle, CTA buttons, direct email & phone links
- **About Me Section** — Bio, achievement metrics (Experience, Projects, Satisfaction)
- **Skills Section** — Categorized tabs with progress bars (Frontend, Backend, Tools)
- **Projects Section** — Filterable cards with live demo and GitHub repo links
- **Contact Section** — Interactive form with toast feedback + click-to-copy contacts
- **Dark / Light Mode Toggle** — Smooth theme switching persisted on the page
- **Smooth Scroll Navigation** — Active section tracking in navbar
- **Fully Responsive** — Mobile, tablet and desktop layouts

## 🛠️ Tech Stack
| Technology | Purpose |
|---|---|
| React 18 | UI Component Framework |
| Tailwind CSS | Utility-First Styling |
| Babel Standalone | In-browser JSX transpilation |
| Vanilla CSS | Custom glassmorphism & animations |
| PowerShell HTTP Server | Local dev server |

## 📁 Project Structure
```
portfolio/
├── index.html                 # HTML entry point
├── .gitignore                 # Git ignore rules
├── package.json               # Project metadata
├── server.ps1                 # Local preview server script
├── public/
│   └── images/               # Project thumbnail images
└── src/
    ├── main.js               # Consolidated React app (all components)
    ├── index.css             # Global styles, glassmorphism, animations
    └── data/
        └── portfolioData.js  # Bio, skills & project data
```

## 🚀 Running Locally
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then open **http://localhost:8000/** in your browser.
